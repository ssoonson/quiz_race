# 🏁 퀴즈 레이스 — 학생들이 각자 태블릿으로 함께하는 3D 퀴즈 달리기

선생님이 방을 만들면 학생들이 태블릿으로 들어와 **4지선다 문제를 풀고, 맞힐 때마다 내 캐릭터가 결승선을 향해 달려갑니다.**
선생님 화면(전자칠판)에는 반 전체의 경기가 3D로, 학생 태블릿에는 **내 캐릭터를 따라가는 3D 화면과 문제**가 나옵니다.

- **선생님 화면:** `teacher.html` — 문제집 만들기 → 방 만들기 → QR·방 코드 → 시작 → 순위 → 결과
- **학생 화면:** `index.html` — 방 코드 + 이름 → 대기 → 문제 풀기 → 결과

## 규칙
- 학생마다 **자기 속도로** 문제를 풉니다. 문제 순서는 학생마다 다르게 섞입니다(옆 친구 따라 하기 방지).
- **맞히면** 한 칸 앞으로 달려갑니다(장애물은 뛰어넘거나 비켜 감).
- **틀리면** 캐릭터가 넘어져 2초 쉬고(설정 가능), 다음 문제로 넘어갑니다. 뒤로 가지는 않습니다.
- 정한 개수(기본 10문제)를 먼저 맞히면 **결승**. 제한 시간(기본 3분)이 끝나거나 모두 결승하면 경기가 끝납니다.
- 순위: ① 결승 도착 순서 ② 맞힌 개수 ③ 마지막으로 맞힌 시각이 빠른 순
- 선생님은 대기실이나 순위표에서 이름을 눌러 **장난 이름을 내보낼 수 있습니다.**
- 경기가 끝나면 **‘같은 학생들과 다시 하기’**로 바로 다음 판을 할 수 있습니다.

## 두 가지 연결 방식
| | 체험 모드 | 온라인 (Firebase) |
|---|---|---|
| 준비 | 없음 (`firebase-config.js`가 비어 있으면 자동) | Firebase 프로젝트 만들기 (아래) |
| 누가 들어올 수 있나 | **같은 컴퓨터·같은 브라우저의 다른 탭**만 | 인터넷이 되는 모든 태블릿 |
| 쓰임 | 미리 해 보기, 시험 | 수업 |

선생님 화면 오른쪽 위에 `🧪 체험 모드` 또는 `🟢 온라인`이 표시됩니다.

## Firebase 준비 (처음 한 번, 약 10분, 무료)
1. https://console.firebase.google.com → **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 **싱가포르(asia-southeast1)** → **잠금 모드로 시작**
3. Realtime Database의 **규칙** 탭 → 내용을 모두 지우고 이 저장소의 `database.rules.json` 내용을 붙여 넣기 → **게시**
4. **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정
5. **Authentication → 설정 → 승인된 도메인**에 사이트 주소의 도메인(예: `아이디.github.io`) 추가
6. 톱니바퀴 → **프로젝트 설정 → 내 앱 → 웹(</>)** → 앱 등록 → 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여 넣기

`firebaseConfig`의 값(apiKey 등)은 웹사이트에 공개되도록 만들어진 식별 정보입니다. 데이터는 3번의 **보안 규칙**이 지킵니다.
- 로그인(익명)한 사람만 읽고 쓸 수 있음
- 방의 설정·문제·진행 상태는 **방을 만든 선생님만** 바꿀 수 있음
- 학생은 **자기 기록만** 쓸 수 있고, 맞힌 개수는 한 번에 1씩만 늘릴 수 있음
- 새 학생은 **대기실일 때만** 들어올 수 있음 (한 방 40명 제한은 앱이 확인합니다. Firebase 규칙으로는 인원 수를 셀 수 없음)

무료 요금제(Spark)는 동시 접속 100명까지라 한 반(40명 이하)에 충분합니다.

## 배포 (GitHub Pages)
저장소 **Settings → Pages → Branch: main / (root) → Save** 후 1~2분 뒤
- 선생님: `https://아이디.github.io/저장소이름/teacher.html`
- 학생: `https://아이디.github.io/저장소이름/` (선생님 화면의 QR 코드로 들어오면 방 코드가 자동으로 채워짐)

## 문제집
- 선생님 브라우저에만 저장됩니다. 다른 컴퓨터로는 **파일로 저장 / 파일 불러오기**(JSON)로 옮깁니다.
- **한꺼번에 붙여넣기:** 한 줄에 한 문제 `문제 | 보기1 | 보기2 | 보기3 | 보기4 | 정답번호(1~4)`.
  엑셀·구글 시트에서 6칸을 그대로 복사해 붙여 넣어도 됩니다.
- 방을 만들 때 완성된 문제(문제와 보기 4개, 정답)만 쓰입니다. 문제를 다 풀면 다시 섞어서 반복됩니다.

## 알아 둘 점
- **정답 보안:** 정답 번호는 방마다 다른 값을 섞은 해시로 저장해 화면에서 바로 보이지 않습니다. 하지만 학생 기기에서 채점하는 방식이라, 개발자 도구를 잘 다루는 학생이 마음먹으면 알아낼 수 있습니다. 완벽하게 막으려면 유료 서버 기능(Cloud Functions)이 필요합니다. 수업용 게임으로는 충분하다고 보았습니다.
- **학생 이름**은 방이 열려 있는 동안 Firebase에 저장됩니다. 수업이 끝나면 선생님 화면의 **방 닫기**를 눌러 지워 주세요. 닫지 않은 방은 그대로 남아 있으니, 가끔 Firebase 콘솔의 Realtime Database에서 `rooms`를 지우면 깨끗해집니다.
- 학생이 새로고침하거나 잠깐 끊겨도 같은 브라우저라면 자기 자리로 돌아옵니다.
- 3D가 느린 태블릿은 그래픽 품질을 자동으로 낮춥니다.

## 폴더 구조
```
index.html / teacher.html     학생 화면 / 선생님 화면
firebase-config.js            Firebase 설정값 (비어 있으면 체험 모드)
database.rules.json           Firebase 보안 규칙 (콘솔에 붙여 넣기)
css/                          base(공통) · game(3D·알림·순위) · teacher · student
js/
  lib/                        Three.js 0.170.0, QR 코드 생성기 (둘 다 MIT)
  net/                        연결: index(고르기) · firebase · local(체험 모드)
  shared/rules.js             규칙: 순위, 문제 순서, 정답 확인, 남은 시간
  shared/scene.js, banner.js  3D 장면 한 벌, 큰 알림
  game/race-view.js           맞힌 개수 → 캐릭터 달리기·넘어짐·만세
  game/                       캐릭터·트랙·카메라 (‘우리 반 콩콩 달리기’와 같은 에셋)
  teacher/                    app(방·경기) · editor(문제집 편집) · quiz-sets(문제집 저장)
  student/app.js              입장·문제 풀기·결과
```
